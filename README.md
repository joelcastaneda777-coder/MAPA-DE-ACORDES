# Mapa de Acordes — base recuperada y SEO piloto

Fuente original: HTML exportado del despliegue de Vercel proporcionado por el propietario.

Incluye el laboratorio musical completo (piano, guitarra, secuenciador, BPM, piano/arpa/pad), metadatos SEO de inicio, y 20 páginas HTML estáticas de acordes.

## Despliegue
Coloca todo el contenido de esta carpeta en la raíz del repositorio y configura Vercel como sitio estático sin comando de compilación. No cambies el dominio canonical hasta tener el dominio propio verificado.
